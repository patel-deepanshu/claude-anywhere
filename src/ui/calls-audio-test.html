Call audio test

Claude Anywhere checks that a call in this browser can hear its voice, and that it can hear the call. It speaks a test phrase into its virtual microphone and plays a short clip in this tab. It takes about 20 seconds. Nothing is uploaded anywhere but to Claude Anywhere on this computer.

Allow the microphone when the browser asks. Leave the browser's microphone setting for this site on Default.

  1. Audio routing
    Switch to the virtual microphone for the test.
  2. Claude Anywhere → this browser
    This page records the microphone while Claude Anywhere speaks.
  3. This browser → Claude Anywhere
    This page plays a clip that Claude Anywhere records.
  4. Restore
    Your microphone becomes the default again.

You can close this tab when the test has finished. Run it again any time with anywhere calls test-audio.
